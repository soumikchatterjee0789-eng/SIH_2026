# WiseGuardian — HTML/CSS/Vanilla JS

This version is converted to a simple static frontend:

- HTML5
- CSS3
- Vanilla JavaScript
- No React
- No Vite
- No TypeScript
- No Tailwind dependency

## Run

Simplest:
1. Open `index.html` in a browser.

Recommended in VS Code:
1. Install the **Live Server** extension.
2. Right-click `index.html`.
3. Choose **Open with Live Server**.

The UI currently uses demo data and local JavaScript state. Backend integration can later be connected through `js/script.js` using the `API_BASE_URL` constant and the S41 REST API contract.

## Important

The current AI Advisor is a local demo response system. It is not connected to Gemini/backend yet.
